Density estimations - iris

This example illustrates the principles underlying three different probabilistic PLSDA models: PLS-LDA, PLS-QDA and PLS-KDEDA (see functions plslda, plsqda, plskdeda).

  • Step-1: PLS scores are computed on the training data {X, Y-dummy}, where Y-dummy is the table of the binary-coded variables of the classes contained in the categorical response variable y. Then observations X are projected on this score space, and the multivariate probability density distribution of these projections are estimated for each class. The estimations assume Gaussian distributions for LDA and QDA (parametric methods), and use non-parametric kernels for KDE.

  • Step-2: The prediction of a given new observation, xnew, is as follows. Observation xnew is projected on the training score space computed in step-1 and, for each class, its location is compared to the density distribution estimated for the class. This determines the probability that xnew belongs to the given class. The class showing the highest probability is chosen as prediction.

In practice, PLS score spaces used for discrimination can have many dimensions. In the present example, to simplify the graphical illustrations, a 2-D score space (2 latent variables) is considered.

The same graphical representation as above can be done with the probability density that is estimated for each class with the three methods.

LDA estimate

In LDA, the Gaussian probability densities are estimated assuming that the classes have the same covariance matrix (W) (see function dmnorm). 

weights = pweight(ones(ntrain))   # observation weights
res = matW(Ttrain, ytrain, weights)
W = res.W * ntrain / (ntrain - nlev)
npoints = 2^7
x1 = LinRange(-4, 4, npoints)
x2 = LinRange(-2, 2, npoints)
z = mpar(x1 = x1, x2 = x2)
grid = reduce(hcat, z)
f = Figure(size = (900, 400))
ax = list(nlev)
for i in eachindex(lev) 
    T = Ttrain[ytrain .== lev[i], :]
    #lims = [[minimum(T[:, j]) maximum(T[:, j])] for j = 1:nlv]
    #x1 = LinRange(lims[1][1], lims[1][2], npoints)
    #x2 = LinRange(lims[2][1], lims[2][2], npoints)
    zfitm = dmnorm(colmean(T), W)   # Gaussian estimate
    zres = predict(zfitm, grid) 
    pred_grid = vec(zres.pred)
    ax[i] = Axis(f[1, i]; title = lev[i], xlabel = "LV1", ylabel = "LV2")
    co = contourf!(ax[i], grid[:, 1], grid[:, 2], pred_grid; levels = 10)
    scatter!(ax[i], T[:, 1], T[:, 2], color = :red, markersize = 10)
    scatter!(ax[i], Ttest[k, 1], Ttest[k, 2], color = :blue, marker = :star5, markersize = 15)
    hlines!(ax[i], 0; linestyle = :dash, color = :grey)
    vlines!(ax[i], 0; linestyle = :dash, color = :grey)
    xlims!(ax[i], -4, 4)
    ylims!(ax[i], -1.7, 1.7)
    Colorbar(f[2, i], co; label = "Density", vertical = false)
end

QDA estimate

In QDA, the classes are assumed to have different covariance matrices (Wi) (see function dmnorm). 

res = matW(Ttrain, ytrain, weights)
Wi = res.Wi
ni = res.ni
npoints = 2^7
x1 = LinRange(-4, 4, npoints)
x2 = LinRange(-2, 2, npoints)
z = mpar(x1 = x1, x2 = x2)

z = mpar(x1 = x1, x2 = x2)
grid = reduce(hcat, z)
f = Figure(size = (900, 400))
ax = list(nlev)
for i in eachindex(lev) 
    T = Ttrain[ytrain .== lev[i], :]
    zS = Wi[i] * ni[i] / (ni[i] - 1)
    zfitm = dmnorm(colmean(T), zS)   # Gaussian estimate
    zres = predict(zfitm, grid)
    pred_grid = vec(zres.pred) 
    ax[i] = Axis(f[1, i]; title = lev[i], xlabel = "LV1", ylabel = "LV2")

    scatter!(ax[i], T[:, 1], T[:, 2], color = :red, markersize = 10)
    scatter!(ax[i], Ttest[k, 1], Ttest[k, 2], color = :blue, marker = :star5, markersize = 15)

Non-parametric KDE estimate

In KDE, the densities in each class are estimated by kernel estimators (see function dmkern). 

npoints = 2^7
x1 = LinRange(-4, 4, npoints)
x2 = LinRange(-2, 2, npoints)
z = mpar(x1 = x1, x2 = x2)
grid = reduce(hcat, z)
f = Figure(size = (900, 400))
ax = list(nlev)
for i in eachindex(lev) 
    T = Ttrain[ytrain .== lev[i], :]
    zfitm = dmkern(T; a = .5)   # KDE estimate
    zres = predict(zfitm, grid)
    pred_grid = vec(zres.pred)
    ax[i] = Axis(f[1, i]; title = lev[i], xlabel = "LV1", ylabel = "LV2")
    co = contourf!(ax[i], grid[:, 1], grid[:, 2], pred_grid; levels = 10)
    scatter!(ax[i], T[:, 1], T[:, 2], color = :red, markersize = 10)
    scatter!(ax[i], Ttest[k, 1], Ttest[k, 2], color = :blue, marker = :star5, markersize = 15)
    hlines!(ax[i], 0; linestyle = :dash, color = :grey)
